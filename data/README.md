# Benchmark Data Repository

This directory serves as the storage location for **raw benchmark outputs** generated by the performance testing suite.

---

## Directory Structure

The data is organized by output type within the `results` folder.

`
data/
└── results/
├── naive_float.csv    # Baseline implementation results
├── tiled_float.csv    # Optimized (tiled) implementation results
└── ...
`

---

## File Descriptions

| Filename | Description                                                     |
| :--- |:----------------------------------------------------------------|
| **`naive_float.csv`** | Performance data for the non-optimized, direct implementation.  |
| **`tiled_float.csv`** | Performance data for the cache-optimized, tiled implementation. |
---

## Data Schema (CSV Format)

All CSV files in this directory share the following column structure:

* **`timestamp`**: ISO 8601 timestamp of the run.
* **`matrix_size`**: The dimension of the input matrix ($N \times N$).
* **`execution_time`**: Time taken to complete the operation (in seconds).
* **`gflops`**: Calculated Giga-FLOPS (Floating Point Operations Per Second).

---

##  Important Notes

- **Automation:** Files in this directory are generated automatically by the benchmark runner. Manual edits may be overwritten.
- **Portability:** Data is stored in plain CSV format to allow easy import into Pandas, Excel, or Gnuplot.
- **Version Control:** This directory is typically excluded from git (via `.gitignore`) to prevent repository bloat, though this `README.md` should remain tracked.
